# Agency Cockpit

**Live app → https://elitanz.github.io/agency-cockpit/**

A mobile-first sales command center for running a local-web-design agency end to end —
from finding a lead to sending the invoice, and turning one-time sites into monthly recurring revenue.

It's a single static `index.html` (no build step, no backend). All your data — lead
statuses, follow-ups, notes, custom leads, your details, goal, and automations — is stored
privately in your own browser via `localStorage`. Use the **Backup** button (save icon,
top-right) to export or restore it.

## Tabs

- **Leads** — your pipeline with a "do this next" focus card, search, filters (incl. a *Due*
  follow-up filter), and per-lead call / text / audit / stage / reminder controls.
- **Outreach** — ready-to-send text, email, DM, and voicemail scripts for any prospect.
- **Pitch** — a website audit/report card, a before/after comparison, and a live mockup generator.
- **Close** — branded proposals and invoices (Print / Save-to-PDF), with recurring automation add-ons.
- **Grow** — a $50k-invested goal dashboard, sites-sold / one-time / MRR stats, editable recurring
  automation offers with copy-paste pitches, and a per-client automation tracker that rolls up into MRR.

## Add to your phone

Open the live link on your phone and **Add to Home Screen** — it launches full-screen like a native app.
